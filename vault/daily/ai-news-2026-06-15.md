### ⚑ For Frank — work-relevant watchlist
- **Multi-vendor / fallback routing is now operational necessity, not best practice.** The Fable 5 recall is a live case study: any production recsys or agent stack should assume a model can vanish overnight. Build provider-agnostic routing (Opus 4.8 / GPT-5.5 / Gemini 3.1 Pro / Kimi) and consider open-weight fallbacks for high-stakes paths.
- **Open-weight agentic coding is catching frontier:** Kimi K2.7 Code (81.1% MCPMark, self-hostable) is a strong hackathon / prototyping option that's immune to recalls — though it needs serious GPU to run locally.
- **MCP remains the portability layer** for cross-model tooling — relevant for any internal agent or recommendation infra meant to outlive a single vendor.
- **Compute-per-dollar framing** (Amodei, Goldman's $7.6T capex) reinforces matching model tier to task in production — cost discipline matters for recsys/agent deployments at scale.
- **Gemini 3.5 Pro (late June)** worth watching for long-context recsys/document workloads (2M tokens) if it lands at the expected price.
