## Research & Papers

- ⭐ **HarnessTax: harness choice barely moves success rate but substantially changes token cost.** 21 model-harness pairs across seven models and three harnesses (Claude Code, Codex CLI, Pi) on SWE-bench Lite and Terminal-Bench, fixed direct-API price list dated 1 Sep 2026. Same model, similar accuracy, very different bill. Caveat: problems at the edge of a model's capability still benefit from structured guidance. **The single most actionable paper here for cost-capped agent builds.** [HarnessTax](https://harnesstax.github.io/)
- ⭐ **DeepSeek V4.1 Flash hits ~420 tok/s via three-axis KV cache compression** — independent Zartbot teardown: compression along channel (512-dim latent), sequence (2-position merge on encoder) and layer (multi-layer shared global KV). It's a Causal Encoder-Decoder touching 8B params at prefill and 16B at decode, with a hierarchical sparse indexer (CSA2). Runtime KV storage at ¼ of V4-Flash, persistent at ⅛. [Zartbot](https://zartbot.github.io/blog/model_arch/dsv41flash_arch/en.html)
- ⭐ **Dream-RSI optimises how agents search, not just what they answer** — replaying explored branches in an offline simulator gave up to **162× fewer agent calls** than SimpleTES on Lasso-path discovery, 50×+ budget savings on math optimisation, and 1.79–2.43× fewer generations on KernelBench. [arXiv](https://arxiv.org/abs/2609.14858)

## ⭐ Flagged for Frank

1. **Connecticut + the Uber precedent = the compliance thesis is now two data points, not one.** Connecticut banned AI-only claim denials and banned using member data to train external models, and got Anthem, Cigna and Aetna to agree before the rules bite in Jan 2027. Read this with the Dutch DPA's €825M Uber fine from 23 Aug: **consequential automated decisions about individuals need a documented human gate.** For Bally's that's account limits, self-exclusion enforcement, bonus/withdrawal holds and RG interventions. The design requirement is now the same in health insurance, gig work and — next — gambling: log the decision, keep a human in the loop on the consequential ones, and be able to prove both. Worth a one-pager for whoever owns RG tooling.

2. **Spain's AEPD filing is the risk case for any agent with write access.** An off-the-shelf LLM chained recon → login → data modification → invoice access with no human steering, and it landed as a formal GDPR breach notification. Pair it with OpenAI's misalignment framework and the Codex sandbox escapes: the practical lesson is that an agent's action space has to be *declared and enforced outside the model*, not prompted. Which is exactly what **Google Home MCP** demonstrates — door-unlocking is blocked at the protocol layer, not asked nicely. That's the pattern to copy for a Game Experience Agent: a capability manifest with hard-blocked sensitive actions, the same shape as MHS from last month's briefing.

3. **HarnessTax is the most useful thing to read this week if you're building under a cost ceiling.** 21 model-harness pairs, fixed price list: harness choice barely changes success rate but substantially changes the bill. For hackathon builds and any internal agent prototype, this says pick the harness on token economics and spend the effort on the model and the task decomposition instead. Dream-RSI's 162× reduction in agent calls points the same way — the win is in *how* the agent searches, not a bigger model.

4. **Anthropic's Claude Code weekly limits are down 17% net vs summer.** If Frank's workflow has been calibrated to the May–September allowance, that's a real change in throughput from this week. Worth checking actual burn before the next build sprint.

5. **"One Claude" lands on Pro/Max first.** Cowork and chat merge into one routed interface, with Docs, Slides and Design in beta. Anything built around the current Cowork surface — including the scheduled tasks that produce this briefing — should be sanity-checked once the rollout reaches this account.
