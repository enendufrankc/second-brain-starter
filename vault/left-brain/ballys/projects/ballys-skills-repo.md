# Ballys Skills Repo

## Overview
Shared innersource library of reusable Claude Code skills for 60+ engineers. Skills organized by functional area with quality tiers (Experimental, Reviewed, Standard).

## Status
- **Live at:** GitLab Pages (temp URL)
- **PIT Status:** DNS/cert ticket raised. No SSO yet.
- **In Use:** Not yet (pending DNS + promotion)
- **Pipeline:** claude-skills feature/marketplace-plugin pipeline FIXED (Apr 15, #2418706 passed after 3 failures)
- **Apollo context:** Complementary to Apollo (Apollo = distribution/package manager, Skills Repo = curation/app store). Not competing.

## Tech Stack
- Skills format: SKILL.md (YAML frontmatter + markdown) + optional scripts/, references/, assets/
- Hosting: GitLab Pages (gitlab.ballys.tech/igaming/tooling/claude-skills)
- Metadata: tier, owner, teams-tested, domain, functional-area
- CI: structure validation, frontmatter validation, marketplace sync, secret scanning, Python syntax, ShellCheck
- Marketplace: generated by sync_marketplace.py, grouped by functional-area
- Distribution: CLI-only (Claude Desktop UI rejects gitlab.ballys.tech — not a supported host)
