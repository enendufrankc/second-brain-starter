# Apollo - iGaming Adoption

## Summary
Volodymyr Pivoshenko presented Apollo, a single binary CLI tool for distributing AI skills, MCPs, and hooks across teams. YAML config, config inheritance, Command Centre telemetry, CI/CD support, silent rollouts.

## Key Points
- Apollo is a package manager / distribution tool for AI skills
- YAML-based configuration with inheritance
- Command Centre for telemetry and monitoring
- Supports CI/CD integration and silent rollouts
- Single binary — no dependencies

## Relation to Skills Repo
- Apollo = distribution / package manager
- Ballys Skills Repo = curation / app store
- Complementary, not competing
- Skills are just prompts — Apollo auto-distributes, Skills Repo lets people choose
